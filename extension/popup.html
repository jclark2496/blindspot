Scans the current tab only when you click Blindspot. Detection runs entirely in your browser; no page data or findings leave your device.

Rules map static indicators to MITRE ATLAS and OWASP LLM risks. Categories include prompt injection, hidden content, data exfiltration, social engineering, MCP attacks, behavioral manipulation, trust boundary violations, permission escalation, and instruction persistence.

Part of the AI security toolchain. Also available as a standalone web scanner and Python CLI.
