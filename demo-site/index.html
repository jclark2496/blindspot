Three short demos that show what humans see, what AI agents ingest, and where Blindspot flags the supply-chain risk.

AI sees: hidden comments, base64 payloads, and instruction suppression.

}
Blindspot flags: MCP-003, MCP-004, MCP-AUDIT-001, MCP-AUDIT-004.
Expected Blindspot result Run with --mcp-audit to add structural findings for shadowed tool names, broad path defaults, and callback URLs.
